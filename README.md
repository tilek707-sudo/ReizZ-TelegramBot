
# ReizZ - Telegram Game Bot 🎰

Полнофункциональный игровой бот для Telegram с рулеткой, слотами и системой экономики.

## Функции

- 🎲 **Минирулетка** (0-12) с ставками на цвета, числа и диапазоны
- 💰 **Система монет** с балансом и историей
- 👤 **Профили** с полной статистикой
- 🎁 **Ежедневные бонусы** (5000 монет каждые 12 часов)
- 💸 **Передача монет** между игроками
- 🎰 **Слот-машина** (Бандит)
- 🏆 **Рейтинг** (топ богатых, топ благотворителей, топ дня)
- 💍 **Система брака** между игроками
- 🎭 **Игровые роли** (Вор, Полиция)
- 📊 **История** всех операций
- 🛡️ **Администраторские команды** (бан, кик, мут)

## Требования

- Python 3.9+
- PostgreSQL или SQLite
- Telegram Bot Token (от @BotFather)

## Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/tilek707-sudo/ReizZ-TelegramBot.git
cd ReizZ-TelegramBot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Конфигурация
Скопируйте `.env.example` в `.env` и заполните данные:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=sqlite:///reizz.db
```

### 4. Запуск бота
```bash
python main.py
```

## Команды для игроков

### Базовые команды (без /)
- `б` или `баланс` - показать баланс
- `профиль` - показать профиль (или профиль того, на кого ответили)
- `история` - показать историю операций
- `рулетка` - начать рулетку
- `+10000` (reply) - перевести монеты другому игроку

### Рулетка
- `1000 на красное` - ставка на красное (2x)
- `1000 на чёрное` - ставка на чёрное (2x)
- `1000 на зеро` - ставка на ноль (14x)
- `1000 на 5` - ставка на число (12x)
- `1000 5-10` - ставка на диапазон (переменный множитель)
- `ва-банк 11` - ставить весь баланс на число
- `го/яхай/башта/айда` - запустить рулетку
- `повторить` - повторить последнюю ставку
- `удвоить` - удвоить последнюю ставку
- `отмена` - отменить все ставки

### Информация
- `ставки` - показать текущие ставки раунда
- `!лог` - последние 20 результатов рулетки
- `лог` - последние 10 результатов
- `топ` - рейтинги (богатых, благотворителей)
- `история` - история операций

### Слот-машина (Бандит)
- `бандит 5000` - сыграть со ставкой

### Социальное
- `пожертвовать 10000` (reply) - пожертвовать монеты игроку

### Модерация (для администраторов)
- `!мут 1м` (reply) - заглушить пользователя на 1 минуту
- `бан 7д` (reply) - забанить на 7 дней
- `кик` (reply) - выкинуть из группы
